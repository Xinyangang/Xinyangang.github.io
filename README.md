# 表情包生成器

一个使用 Next.js 和 Tailwind CSS 构建的表情包生成网站。

## 开始使用

首先，安装依赖：

```bash
npm install
# 或
yarn install
# 或
pnpm install
```

然后，运行开发服务器：

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看结果。

## 项目结构

- `app/` - Next.js App Router 目录
  - `page.tsx` - 首页
  - `layout.tsx` - 根布局
  - `globals.css` - 全局样式
